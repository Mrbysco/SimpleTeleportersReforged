
### New Features

#### Enhanced Ender Shard
- New item that allows cross-dimensional teleportation  
- Crafted by combining an Ender Shard with an Echo Shard  
- New artwork for both the Ender Crystal and Enhanced Ender Crystal

#### Hearth Crystal Overhaul
- Complete redesign. Teleport location is now player-bound (stored on the player, not the item)  
- Rechargeable with Ender Pearls (shapeless recipe)  
- 20 charges, consumed on each teleport  
- Improved UX with charge bar display and tooltips  
- 3 second channel time before teleporting

#### Teleporter Improvements
- Added dyeing functionality. Right-click a teleporter with dye to change its color  
- Teleporters can now teleport any entity, not just players  
- Added redstone control support  
- Fixed display names not showing after chunk unload

#### Quality of Life
- All mod items moved to a dedicated Creative Tab  
- Optional GuideME integration for in-game documentation  
- Jade tooltip support added in the dev environment

### Recipes
- Smelting: Ender Pearl → Ender Shard  
- Smelting: Ender Shard → Hearth Crystal  
- Shapeless: Ender Shard + Echo Shard → Enhanced Ender Shard  
- Shapeless: Hearth Crystal + Ender Pearl → Hearth Crystal (recharged)
