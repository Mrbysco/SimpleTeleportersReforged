* Added Sable (Create: Aeronautics) integration: sneak + right-click any block of an airship with an Ender Shard to bind to that ship, then walk onto a teleporter loaded with the shard to be teleported to the ship's current position
* Airship bindings track the ship as it moves, including same-dimension flight; basic Ender Shards still refuse to teleport to a ship in another dimension (Enhanced bypasses, matching existing rules)
* Tooltip and a chat confirmation now indicate when a shard is bound to an airship vs. a fixed location
* Added server config option `enableSableIntegration` (default on) to disable the Sable integration
* Does nothing when Sable is not installed
